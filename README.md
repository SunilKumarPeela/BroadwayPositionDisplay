# Broadway Design — Landing Page

Use CSS **display** and **position** to improve layout:
- Fixed header with a centered nav
- Full-bleed jumbotron hero
- Three supporting sections (Design, Develop, Deploy)

## 🚀 Quick Start
1. Open `index.html` in your browser.
2. Tweak text/images as you like.

## 🧰 What’s Inside
- `position: fixed` header
- Inline/flex navigation
- Responsive supporting columns
- Smooth anchor scrolling (`#about`, `#work`, `#team`, `#contact`)
